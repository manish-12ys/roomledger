## ✨ Overview

**RoomLedger** is a modern and elegant expense management application crafted for:

- 👥 Roommates
- 🏠 Shared apartments
- 💸 Personal finance management
- 📊 Expense analytics

Built with **Flutter**, RoomLedger focuses on:

- ⚡ Smooth performance
- 🌑 AMOLED-first design
- 🔒 Complete local privacy
- 📱 Clean modern user experience
- 💎 Premium visual aesthetics

---

RoomLedger follows a carefully designed **AMOLED dark visual system** optimized for modern OLED displays.

### 🎨 UI Characteristics

- Pure AMOLED black backgrounds

# 🧠 Core Architecture

## 🔢 Integer-Based Currency Engine

RoomLedger uses an integer-first financial architecture to avoid floating-point precision issues.

### Benefits
- Accurate calculations
- Reliable splits
- Stable financial records
- No rounding inconsistencies

---

## 🛡️ Defensive SQLite System

The app implements safe transaction-based cleanup strategies instead of relying entirely on native cascade operations.

### Advantages
- Improved stability
- Better cross-device consistency
- Safer debt settlements
- Reliable database operations

# 🛠️ Getting Started

## Prerequisites

```bash
Flutter SDK >= 3.3.0
Dart SDK >= 3.0.0
```

---

## 📥 Installation

### Clone Repository

```bash
git clone https://github.com/manish-12ys/roomledger.git
cd roomledger
```

### Install Dependencies

```bash
flutter pub get
```

### Run Static Analysis

```bash
flutter analyze
```

### Execute Tests

```bash
flutter test
```

### Run Application

```bash
flutter run
```
